This is run on Curtain

Curtain allows you to create ctf challanges and deploy them easily, allowing users to easily deploy their own isolated environments through two other tools called Conductor and Musician.

Conductor does this by acting as a vpn and allowing users computers to act as if they are on the same network while also only giving them access to their own environment.

This does not limit them to only one machine though, developers can create complex networks of interconnected virtual machines or real machines for the user to access

Each user is assigned a unique session ID that is used to identify which environment they can access, which is used to determine the users environment
